# Mouchkilti (مشكلتي) - Signalement de Problèmes Urbains

**Mouchkilti** est une application mobile Android permettant aux citoyens de signaler facilement les incidents et anomalies urbaines (nids-de-poule, lampadaires défaillants, dépôts sauvages d'ordures, fuites d'eau) aux services compétents.

---

## 📱 Fonctionnalités Principales

* **Authentification Citoyenne :** Connexion simple et sécurisée avec validation des champs.
* **Fil d'actualité des incidents :** Consultation de la liste des signalements récents avec statut d'avancement (En attente, En cours, Résolu).
* **Cartographie des Incidents :** Visualisation géographique des signalements sous forme de repères interactifs.
* **Nouveau Signalement :** Déclaration rapide d'un problème avec catégorie, niveau d'urgence, description, localisation et date du constat.
* **Détails & Engagement Citoyen :** Consultation détaillée d'un incident avec possibilité de confirmer son existence (+1 vote).
* **Suivi Personnel :** Espace citoyen pour suivre en temps réel l'évolution de ses propres déclarations.

---

## 🛠️ Technologies Utilisées

* **Plateforme :** Android
* **Langage :** Java
* **UI / Design :** XML Layouts
* **Composants :** ListView, Custom Adapters, Menus, Dialogs (Alert & DatePicker)

---

## 🚀 Installation & Lancement

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/AyoubEttalbi/Mouchkilti.git
   ```
2. Ouvrir le projet dans **Android Studio**.
3. Synchroniser Gradle et lancer l'application sur un émulateur ou appareil Android.
